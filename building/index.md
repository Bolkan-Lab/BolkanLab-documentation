## Introduction

This section is a central repository for the documentation regarding the **building** of virtual reality rigs at the Bolkan Lab, Princeton Neuroscience Institute.

Building documentation is divided into modules; each module contains a detailed explanation of the assembly process. CAD files for the full rig can be placed under `building/assets/drawings/` and linked with a plain download link, and the parts list can live in a shared spreadsheet linked from here.

If you need any other file, another format, need help, or just want to reach out, don't hesitate to contact the Bolkan Lab team.

## Recommended steps to assemble

1. Start with the [example module](/building/example-module.html) — replace this list with the real assembly order once the modules exist.
2. Each step should link to the specific heading it refers to, e.g. [module assembly](/building/example-module.html#assembly), so readers can jump straight there.
